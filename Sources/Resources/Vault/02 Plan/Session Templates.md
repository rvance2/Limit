# Session Templates

Five session types. Each names its warm-up, its order, its stop rules, and what to cut when short on time.

- [[S1 Finger Priority]] — Monday. Most important session of the week.
- [[S2 Limit Boulder]] — Friday indoor alternative.
- [[S3 Power and Contact]] — Wednesday. Rate work.
- [[S4 Volume and Skill]] — Tuesday in Block 1 and reduced weeks. Low intensity, high learning.
- [[S5 Outdoor Project Day]] — Friday when conditions allow.
- [[S6 Skill and Pull]] — Tuesday in Blocks 2-4. S4 with the pull block attached.

## Universal warm-up

Fifteen to twenty minutes, every session, no exceptions. Cold fingers on a hangboard is how pulleys go.

1. Five minutes general: walk, bike, arm circles. Raise temperature.
2. [[Shoulder Protocol]] items 1, 4, 5 as activation, one set each.
3. Three easy boulders, progressively less easy. Nothing near limit. **Name one focal point before starting** — [[Focal Point Warm-Up]]. One, not two, written in the log.
4. Progressive hangs: 3-4 sets from ~50% to 90% of the day's working load if I've already climbed, 6-8 if not. The last set tells me set one's load.

That ramp is López's protocol and it doubles as load calibration for the day. Not optional on a finger day.

## Cut order when short on time

[[Lower Limb Resilience]], [[Tension Circuit]], rows, [[Style Roulette]], the last set of the primary finger method.

Never cut: the warm-up, [[Shoulder Protocol]], the first three sets of the primary finger method, or the scapular activation before [[One Arm Progression]]. If there isn't time for the activation, there isn't time for the one-arm work.

## Session RPE

One number at the end of every session: 1-10, times minutes, into [[Log Templates]]. Feeds the weekly load figure in [[Readiness Monitoring]].
