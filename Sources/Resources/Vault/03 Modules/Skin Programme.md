# Skin Programme

Sweaty skin, already on Antihydral. This is about doing it with a schedule and a log rather than by feel, because the failure mode of Antihydral is overshoot and splits.

## Daily baseline

- **After every session:** wash, moisturise, lightly file rough callus edges.
- **Before bed:** generous moisturiser. Cotton gloves overnight when chasing recovery hard.
- Hydrated skin regenerates faster than dry skin. The tension at the centre of my problem: dry it for friction, moisturise it for recovery, on different clocks.

## Antihydral schedule

Timing consensus: apply 2-3 days before I need the effect, effects last around a week from one application, wide individual variation. Repeated application stacks; overshoot gives glassy, brittle skin that splits.

Conservative start, project day Saturday:

| Day | Action |
| --- | --- |
| Wednesday night | Thin layer, fingertips and palms. Avoid creases. Wash off after 30-60 min. |
| Thursday | Moisturise heavily. No Antihydral. |
| Friday | Moisturise. Light file if needed. Assess: too dry, correct, still sweaty? |
| Saturday | Project day. Adjust next week's dose from Friday's assessment. |

Escalate only if Friday says "still sweaty." The aggressive regimes — every other night in the week before a trip — come from climbers at 5.15 who've calibrated their own skin over years. Not a starting point.

## Non-negotiables

- **Off the finger creases.** Repeated application there causes splitting over time.
- **Moisturise while using it.** The step I'd skip and why I'd split.
- **Not the night before.** The effect is delayed; I'd get the drying without the settling.

## Calluses

File the evening after a session, not before. Freshly filed skin is thinner and a hard session goes through the layer. Filing 24-48 h before a project day lets it settle.

Target: flat and even, no proud edge at the callus boundary. That edge is what catches and becomes a flapper. ~120 grit to reduce thickness, 220-400 to finish. Finish smooth or I've created new micro-edges.

Antihydral-dried callus files differently — harder, brittle, comes off in flakes. Easier to over-file. Go carefully.

## The log

Every session, one number and one note.

```
Date | skin 1-5 | Antihydral? | condition: (sweaty / correct / dry / glassy / split)
```

Five is fresh and perfect, one is destroyed. After six weeks I'll be able to see my own dose-response curve, which no article can give me.

## Timelines that constrain the plan

A split takes up to a full week. Muscles recover in two days. Climbed hard Monday → muscles ready Wednesday, skin Thursday. Skin is the binding constraint on attempt count, which makes it a direct input to [[Attempt Discipline]].
