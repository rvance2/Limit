# How To Use This Vault

## Opening it

Whole folder as a vault, or as a subfolder of an existing one. No plugins. The mermaid map in [[00 START HERE]] renders natively.

To make the graph readable: Depth 2, Group by tag on, `#factor` one colour, `#module` another, `#plan` a third. Filter `-path:"04 Testing"` when I only want structure.

## Daily loop

1. Morning: four numbers into the log, per [[Readiness Monitoring]].
2. Pre-session: open the [[Session Templates]] note. Read the stop rules.
3. During: log loads, not feelings. One line of feeling at the end.
4. After: skin check per [[Skin Programme]]. Shoulder work if it's a prescribed day.

## Weekly loop

Sunday, twenty minutes. Three questions in writing, from [[Log Templates]]:

- Did I hit the prescribed load on the priority module, or quietly regress it?
- What limited me most this week, and is there a module for it?
- Is next week reduced?

Question one is the one that decides whether any of this does anything. It's also the one I'll want to skip.

## Conventions

`#factor` = reality. `#module` = actions. `#plan` = sequence.

Doses use Eva López notation. `3 x MAW Hangs x 20mm x 10" (3) :3'` = three sets, added weight, 20 mm edge, ten-second hangs, three-second margin before failure, three minutes rest. Full explanation in [[Max Hangs]].

"Stop rule" means stop. Not consider stopping.

Numbers in factor notes carry an n and a source. No number means it's my opinion, and the note says so.
